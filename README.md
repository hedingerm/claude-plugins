# claude-plugins

My Claude Code plugins and mods, as one marketplace. Add it once, then install whatever you need from it.

```
/plugin marketplace add hedingerm/claude-plugins
```

## Plugins

| Plugin | What it does | Install |
| --- | --- | --- |
| [image-preview](https://github.com/hedingerm/image-preview) | Inline image previews in Ghostty and kitty: under every image Claude reads, and on demand with `/img` | `/plugin install image-preview@hedingerm` |

Each plugin lives in its own repo; this one only lists them. `/plugin marketplace update hedingerm` pulls new versions.
